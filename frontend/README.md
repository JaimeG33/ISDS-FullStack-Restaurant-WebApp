# Frontend

React + TypeScript + Vite. Run commands from the repository root:

```sh
npm install
npm run dev
```

`src/App.tsx` is the starter screen, `src/data/` holds sample data,
`src/components/` is for reusable UI, `src/pages/` is for screens, and
`src/services/` is reserved for future API clients.

See [the repository README](../README.md) and [Figma setup](../docs/figma-setup.md).
